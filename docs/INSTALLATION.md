# Instalação e atualização

Clonar `https://github.com/mxcapellani/CRIE-CENAS-VARIADAS.git`. Copiar `.agents/skills/crie-cenas-variadas/` mantendo nome e referências para a área aceita pelo host. Solicitar análise de uma imagem realmente acessível com dimensões disponíveis.

A Skill escreve prompts para geradores com referência; não gera imagens automaticamente. Suporte real a proporções incomuns deve ser confirmado no gerador. Sem visão, não alegar análise. Sem dimensões, não adivinhar a razão exata.

Na atualização, preservar exatamente cinco pares, geometria, luz e ratio. Executar validação, repetir casos comparativos relevantes e documentar regressões sem misturar aprovação textual com precisão 3D.
